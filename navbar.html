🌐 Responsive Navigation Bar

Learn how to build a modern responsive navigation bar using CSS Flexbox.

📖 Project Overview

In this project, you will create a responsive navigation bar. You will learn how to arrange links using Flexbox and make the navigation adapt to different screen sizes.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of CSS.
  • Understanding of Flexbox.
  • Basic knowledge of Media Queries.

💻 Source Code


<nav>
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Services</a>
    <a href="#">Contact</a>
</nav>


nav{
background:#222;
display:flex;
justify-content:center;
gap:20px;
padding:20px;
}

nav a{
color:white;
text-decoration:none;
font-size:20px;
font-weight:bold;
transition:.3s;
}

nav a:hover{
color:#00BFFF;
}

@media(max-width:768px){

nav{

flex-direction:column;

align-items:center;

}

}

📖 Code Explanation

1. Flexbox

The display: flex property arranges the navigation links in one row.

2. Spacing

The gap property adds space between the links.

3. Hover Effect

The :hover selector changes the link color when the mouse moves over it.

4. Responsive Design

The @media rule changes the navigation layout on smaller screens.

Home About Services Contact
