🧮 Python Calculator Project

Learn how to build a simple calculator using Python.

📖 Project Overview

In this project, you will build a calculator that can perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

📋 Requirements

  • Python 3 installed on your computer.
  • Basic knowledge of print() and input().
  • Understanding of if, elif, and else statements.
  • Basic arithmetic operators (+, -, *, /).

💻 Source Code


op = input("Choose (+, -, *, /): ")

num1 = float(input("First number: "))
num2 = float(input("Second number: "))

if op == "+":
    print(num1 + num2)

elif op == "-":
    print(num1 - num2)

elif op == "*":
    print(num1 * num2)

elif op == "/":
    if num2 != 0:
        print(num1 / num2)
    else:
        print("Cannot divide by zero")

else:
    print("Invalid operator")

📖 Code Explanation

1. Get the operator

The program asks the user to choose an operator: +, -, *, or /.

2. Get the numbers

The program asks the user to enter two numbers using float() so decimal numbers are also accepted.

3. Check the operator

The if, elif, and else statements determine which operation should be performed.

4. Division by zero

Before division, the program checks whether the second number is equal to zero. If it is, Python displays an error message instead of crashing.

5. Invalid operator

If the user enters an unsupported operator, the program displays Invalid operator.
