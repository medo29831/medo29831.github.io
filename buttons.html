🎨 Colorful Buttons

Learn how to create beautiful buttons using CSS.

📖 Project Overview

In this project, you will learn how to style buttons using CSS. You will change colors, borders, rounded corners, hover effects, and transitions.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of CSS.
  • Understanding of colors.
  • Understanding of hover effects.

💻 Source Code


<button class="btn">
Click Me
</button>


.btn{
background:#2196F3;
color:white;
padding:15px 30px;
border:none;
border-radius:10px;
font-size:20px;
cursor:pointer;
transition:.3s;
}

.btn:hover{
background:#1565C0;
transform:scale(1.05);
}

📖 Code Explanation

1. Background Color

The background property changes the button color.

2. Text Color

The color property changes the text color.

3. Rounded Corners

The border-radius property creates rounded corners.

4. Hover Effect

The :hover selector changes the button style when the mouse moves over it.
