🎨 CSS Programming

Learn how to style beautiful websites using CSS. CSS controls colors, layouts, fonts, animations, and much more.

📖 What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML pages by changing colors, fonts, spacing, layouts, animations, and responsive designs.

CSS was first introduced in 1994 by Norwegian engineer Håkon Wyom Lie, who was then working at CERN with Berners-Lee. Two years later, the World Wide Web Consortium (W3C) adopted the first standardized CSS specification, called CSS1.

⭐ Features of CSS

  • Easy to Learn
  • Makes Websites Beautiful
  • Responsive Design
  • Animations & Effects
  • Works with HTML
  • Supported by All Browsers

💻 First CSS Program


body{
    background: black;
    color: white;
}

h1{
    color: deepskyblue;
}

📖 Code Explanation

background changes the page background color.

color changes the text color.

body styles the whole webpage.

h1 styles the main heading.

🖥️ Output

Blue Heading on Black Background
