🏦 Bank Database

Learn how to create a simple bank database using SQL.

📖 Project Overview

This project creates a database to store bank customer information, including account number, customer name, account type, and balance.

📋 Requirements

  • MySQL or SQLite installed.
  • Basic SQL knowledge.
  • Understanding of CREATE TABLE.
  • Understanding of INSERT and SELECT.

💻 Source Code


CREATE TABLE Accounts (

    AccountID INT PRIMARY KEY,

    CustomerName VARCHAR(50),

    AccountType VARCHAR(20),

    Balance DECIMAL(10,2)

);

INSERT INTO Accounts
VALUES

(1001,'Ahmed Ali','Savings',12000.00),

(1002,'Sara Mohamed','Current',8500.00),

(1003,'Omar Hassan','Savings',15400.00);

SELECT * FROM Accounts;

📖 Code Explanation

CREATE TABLE creates the Accounts table.

INSERT INTO adds customer records.

SELECT * displays all account information.

🖥️ Output

AccountID | CustomerName | AccountType | Balance 1001 | Ahmed Ali | Savings | 12000.00 1002 | Sara Mohamed | Current | 8500.00 1003 | Omar Hassan | Savings | 15400.00
