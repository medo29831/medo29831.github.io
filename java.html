☕ Java Programming

Learn one of the most popular object-oriented programming languages. Java is powerful, secure, and used to build desktop, web, and Android applications.

📖 What is Java?

Java is a high-level, object-oriented programming language developed by James Gosling at Sun Microsystems in 1995. It follows the principle "Write Once, Run Anywhere", which means Java programs can run on different operating systems without modification.

Java was created by James Gosling at Sun Microsystems and officially released in 1995. It is one of the world's most popular object-oriented programming languages and follows the principle "Write Once, Run Anywhere."

⭐ Features of Java

  • Object-Oriented Programming (OOP)
  • Platform Independent
  • Simple Syntax
  • Secure
  • High Performance
  • Large Community
  • Used for Android Development
  • Open Source Tools Available

💻 First Java Program


public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, World!");

    }

}

📖 Code Explanation

public class Main creates the main class.

public static void main() is the starting point of every Java program.

System.out.println() prints text on the screen.

🖥️ Output

Hello, World!

☕ Install Java

How to install Java on your device?

  • 🪟 Windows
  • 🍎 macOS
  • 🐧 Linux
  • 💻 ChromeOS

🪟 Install Java on Windows

Follow these steps to install Java on Windows:

  1. Visit the official Oracle Java website.
  2. Download the latest Java Development Kit (JDK).
  3. Run the installer.
  4. Follow the installation instructions.
  5. Open Command Prompt.
  6. Type the following command:

java -version

If the Java version appears, the installation was successful. ✅

🍎 Install Java on macOS

  1. Download the JDK for macOS.
  2. Open the installer.
  3. Complete the installation.
  4. Open Terminal.
  5. Run:

java -version

🐧 Install Java on Linux

Update the package list: 


sudo apt update

Install Java: 


sudo apt install default-jdk

Check the version: 


java -version

💻 Install Java on ChromeOS

  1. Enable Linux Development Environment.
  2. Open Terminal.
  3. Run:

sudo apt install default-jdk
