📋 Python To-Do List Project

Learn how to build a simple To-Do List using Python.

📖 Project Overview

In this project, you will build a To-Do List program that allows users to add, view, and manage their daily tasks using Python.

📋 Requirements

  • Python 3 installed on your computer.
  • Basic knowledge of print() and input().
  • Understanding of if, elif, and else statements.
  • Basic knowledge of lists and loops.

💻 Source Code



tasks = []


while True:

    print("1. Add Task")
    print("2. Show Tasks")
    print("3. Exit")


    choice = input("Choose: ")


    if choice == "1":

        task = input("Enter your task: ")

        tasks.append(task)

        print("Task added successfully!")


    elif choice == "2":

        print("Your Tasks:")

        for task in tasks:

            print(task)


    elif choice == "3":

        print("Goodbye!")

        break


    else:

        print("Invalid choice")

📖 Code Explanation

1. Create a task list

The program creates an empty list called tasks to store all tasks.

2. Add tasks

The user enters a task and the program saves it using append().

3. Show tasks

The program uses a for loop to display all saved tasks.

4. Menu system

The user chooses what action they want to perform: add tasks, view tasks, or exit.

5. Exit the program

The break statement stops the loop and closes the program.
