🎲 Guess the Number

Learn how to create a number guessing game using Java.

📖 Project Overview

In this project, you will create a game where the computer generates a random number and the player tries to guess it.

📋 Requirements

  • Java JDK installed.
  • Basic knowledge of variables.
  • Scanner class.
  • Random class.
  • if / else statements.
  • Loops.

💻 Source Code


import java.util.Random;
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Random random = new Random();
        Scanner input = new Scanner(System.in);

        int secret = random.nextInt(100) + 1;
        int guess;

        System.out.println("Guess a number between 1 and 100");

        do{

            System.out.print("Your guess: ");
            guess = input.nextInt();

            if(guess > secret){
                System.out.println("Too high!");
            }
            else if(guess < secret){
                System.out.println("Too low!");
            }
            else{
                System.out.println("Correct!");
            }

        }while(guess != secret);

        input.close();

    }

}

📖 Code Explanation

1. Random

The Random class generates a random number between 1 and 100.

2. Scanner

Scanner reads the player's guess from the keyboard.

3. do...while Loop

The loop continues until the player guesses the correct number.

4. if / else

The program tells the player if the guess is too high, too low, or correct.
