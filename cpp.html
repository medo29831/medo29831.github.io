💻 C++ Programming

Learn one of the most powerful programming languages in the world. C++ is fast, powerful, and used in software development, games, and systems programming.

📖 What is C++?

C++ is a high-level programming language created by Bjarne Stroustrup in 1979. It is an extension of the C programming language. C++ is widely used in game development, operating systems, embedded systems, desktop applications, and competitive programming.

The C++ programming language was invented by Danish computer scientist Bjarne Stroustrup at AT&T Bell Labs in 1979. It originated from an analysis of the UNIX kernel to check how easily it could be distributed across a network.

⭐ Features of C++

  • Fast Performance
  • Object-Oriented Programming
  • Powerful Memory Control
  • Cross Platform
  • Large Community
  • Used in Game Development

💻 First C++ Program



#include <iostream>

using namespace std;


int main() {

    cout << "Hello, World!";

    return 0;

}

📖 Code Explanation

#include <iostream> is a library that allows the program to use input and output functions.

cout is used to display text on the screen.

main() is the main function where the C++ program starts running.

return 0; means that the program finished successfully.

🖥️ Output

Hello, World!

💻 Install C++

How to download and install C++ on your device?

C++ needs a compiler to convert the code into a program that the computer can run.

The most common operating systems for C++ are:

  • 🪟 Windows
  • 🍎 macOS
  • 🐧 Linux
  • 💻 ChromeOS

How to Install C++ on Windows 🪟

Steps:

  1. Download a C++ compiler such as MinGW or use Visual Studio.
  2. Install the compiler on your computer.
  3. Add the compiler to PATH.
  4. Open Command Prompt.
  5. Check the compiler installation: 


g++ --version

If the compiler version appears, the installation was successful ✅

How to Install C++ on Linux 🐧

Steps:

  1. Open Terminal.
  2. Update packages: 


sudo apt update

Install the C++ compiler: 



sudo apt install g++

Verify Installation



g++ --version
