🎲 Guess the Number

Learn how to create a number guessing game using C#.

📖 Project Overview

In this project, the computer generates a random number, and the player keeps guessing until the correct number is found.

📋 Requirements

  • .NET SDK installed.
  • Visual Studio or Visual Studio Code.
  • Basic knowledge of variables.
  • Random class.
  • while loop.
  • if / else statements.

💻 Source Code


using System;

class Program
{
    static void Main()
    {
        Random random = new Random();

        int secret = random.Next(1, 101);
        int guess = 0;

        Console.WriteLine("Guess a number between 1 and 100");

        while(guess != secret)
        {
            Console.Write("Your guess: ");
            guess = Convert.ToInt32(Console.ReadLine());

            if(guess > secret)
            {
                Console.WriteLine("Too High!");
            }
            else if(guess < secret)
            {
                Console.WriteLine("Too Low!");
            }
            else
            {
                Console.WriteLine("Correct! You Win!");
            }
        }
    }
}

📖 Code Explanation

1. Random

The Random class generates a random number between 1 and 100.

2. while Loop

The loop continues until the correct number is guessed.

3. if / else

The program tells the player whether the guess is too high, too low, or correct.

🖥️ Output
