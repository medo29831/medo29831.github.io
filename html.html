🌐 HTML Programming

Learn the language used to build the structure of every web page. HTML is the foundation of web development.

📖 What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages. HTML describes elements such as headings, paragraphs, images, links, tables, forms, and much more.

HTML was developed by Tim Berners-Lee, the famous British computer scientist.

⭐ Features of HTML

  • Easy to Learn
  • Simple Syntax
  • Supported by All Browsers
  • Works with CSS and JavaScript
  • Perfect for Building Websites
  • Open Standard

💻 First HTML Program


<!DOCTYPE html>
<html>

<head>
    <title>My First Page</title>
</head>

<body>
    <h1>Hello, World!</h1>
</body>

</html>

📖 Code Explanation

<!DOCTYPE html> tells the browser that this document is written in HTML5.

<html> is the root element of the web page.

<head> contains information about the page such as the title.

<body> contains everything that appears on the web page.

<h1> creates a main heading.

🖥️ Output

Hello, World!

💻 How to Start Writing HTML

What do you need?

  • A web browser (Google Chrome, Microsoft Edge, Firefox, etc.).
  • A text editor such as Visual Studio Code or Notepad++.
  • Basic knowledge of HTML tags.

📝 Steps to Create Your First HTML Page

  1. Open your code editor.
  2. Create a new file.
  3. Save it with the extension .html.
  4. Write your HTML code.
  5. Save the file.
  6. Open it in your web browser.
