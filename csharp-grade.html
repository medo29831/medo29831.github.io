📚 Student Grade Calculator

Learn how to calculate a student's grade using C#.

📖 Project Overview

This project reads a student's score, calculates the grade, and determines whether the student passed or failed.

📋 Requirements

  • .NET SDK installed.
  • Visual Studio or Visual Studio Code.
  • Variables.
  • if / else if / else statements.
  • Console input and output.

💻 Source Code


using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter your score: ");

        int score = Convert.ToInt32(Console.ReadLine());

        if(score >= 90)
            Console.WriteLine("Grade: A");

        else if(score >= 80)
            Console.WriteLine("Grade: B");

        else if(score >= 70)
            Console.WriteLine("Grade: C");

        else if(score >= 60)
            Console.WriteLine("Grade: D");

        else
            Console.WriteLine("Grade: F");
    }
}

📖 Code Explanation

1. Input

The program asks the user to enter the student's score.

2. Conditions

The program uses if / else if statements to determine the correct grade.

3. Output

The corresponding letter grade is displayed on the screen.

🖥️ Output

Enter your score: 85 Grade: B
