👤 HTML Personal Profile Page

Learn how to create a simple personal profile page using HTML.

📖 Project Overview

In this project, you will build your own personal profile page. The page will include your name, photo, short biography, skills, hobbies, and contact information.

📋 Requirements

  • Basic knowledge of HTML tags.
  • Understanding of headings and paragraphs.
  • Knowledge of images and links.
  • Basic knowledge of lists.

💻 Source Code


<!DOCTYPE html>
<html>

<head>
    <title>My Profile</title>
</head>

<body>

<h1>Mohamed</h1>

<img src="profile.jpg" alt="My Photo" width="200">

<p>
Hello! I am learning HTML and web development.
</p>

<h2>My Skills</h2>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>Python</li>
</ul>

<a href="https://github.com/">
Visit My GitHub
</a>

</body>

</html>

📖 Code Explanation

1. Add Your Name

Use the <h1> tag to display your name.

2. Add Your Photo

Use the <img> tag to display your personal image.

3. Write About Yourself

Use the <p> tag to write a short biography.

4. Create a Skills List

Use the <ul> and <li> tags.

5. Add a Link

Use the <a> tag to create a clickable link.

🖥️ Output

👤 Mohamed

🎯 Exercise

Create your own personal profile page that includes:

  • Your name.
  • Your photo.
  • A short paragraph about yourself.
  • A list of your skills.
  • A link to your GitHub or another website.
