🛒 Online Store Database

Learn how to create a simple online store database using SQL.

📖 Project Overview

This project creates a Products table for an online store. It stores product names, prices, and stock quantities.

📋 Requirements

  • MySQL or SQLite installed.
  • Basic SQL knowledge.
  • Understanding of CREATE TABLE.
  • Understanding of INSERT and SELECT.

💻 Source Code


CREATE TABLE Products (

    ID INT PRIMARY KEY,

    ProductName VARCHAR(50),

    Price DECIMAL(10,2),

    Quantity INT

);

INSERT INTO Products
VALUES

(1,'Laptop',35000,8),

(2,'Keyboard',600,25),

(3,'Mouse',350,40);

SELECT * FROM Products;

📖 Code Explanation

CREATE TABLE creates a Products table.

INSERT INTO inserts new products into the table.

SELECT * displays all products.

🖥️ Output

ID | ProductName | Price | Quantity 1 | Laptop | 35000 | 8 2 | Keyboard | 600 | 25 3 | Mouse | 350 | 40
