🖼️ HTML Image Gallery

Learn how to create a simple image gallery using HTML.

📖 Project Overview

In this project, you will build an image gallery webpage. The page will display multiple images with captions in a clean and organized layout.

📋 Requirements

  • Basic knowledge of HTML.
  • Understanding of images.
  • Knowledge of headings and paragraphs.
  • Basic knowledge of folders and file paths.

💻 Source Code


<!DOCTYPE html>
<html>

<head>
    <title>Image Gallery</title>
</head>

<body>

<h1>My Image Gallery</h1>

<img src="images/photo1.jpg" alt="Photo 1" width="250">

<p>Beautiful Nature</p>

<img src="images/photo2.jpg" alt="Photo 2" width="250">

<p>Mountain View</p>

<img src="images/photo3.jpg" alt="Photo 3" width="250">

<p>Sunset</p>

</body>

</html>

📖 Code Explanation

1. Create the Page Title

Use the <title> tag to name your webpage.

2. Add a Heading

Use the <h1> tag to display the gallery title.

3. Display Images

Use the <img> tag to add images to the page.

4. Add Captions

Use the <p> tag to describe each image.

🖥️ Output

🖼️ My Image Gallery

🎯 Exercise

Create your own image gallery that includes:

  • At least three images.
  • A caption below each image.
  • A main title for the gallery.
  • Organize the images in a clean layout.
