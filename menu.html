🍽️ HTML Restaurant Menu

Learn how to create a simple restaurant menu using HTML.

📖 Project Overview

In this project, you will create a restaurant menu webpage. The page will display different food categories, menu items, and their prices in a clean and organized layout.

📋 Requirements

  • Basic knowledge of HTML.
  • Understanding of headings and paragraphs.
  • Knowledge of lists.
  • Basic knowledge of tables.

💻 Source Code


<!DOCTYPE html>
<html>

<head>
    <title>Restaurant Menu</title>
</head>

<body>

<h1>My Restaurant</h1>

<h2>🍕 Pizza</h2>

<ul>
    <li>Margherita - $8</li>
    <li>Pepperoni - $10</li>
</ul>

<h2>🍔 Burgers</h2>

<ul>
    <li>Classic Burger - $7</li>
    <li>Cheese Burger - $9</li>
</ul>

<h2>🥤 Drinks</h2>

<ul>
    <li>Cola - $2</li>
    <li>Orange Juice - $3</li>
</ul>

</body>

</html>

📖 Code Explanation

1. Restaurant Name

Use the <h1> tag to display the restaurant name.

2. Food Categories

Use the <h2> tag for each menu category.

3. Menu Items

Use the <ul> and <li> tags to list food items.

4. Prices

Write the price beside each item.

🖥️ Output

🍽️ My Restaurant

🎯 Exercise

Create your own restaurant menu that includes:

  • The restaurant name.
  • At least three food categories.
  • At least two items in each category.
  • The price of each item.
