👨 Employee Database

Learn how to create and manage an employee database using SQL.

📖 Project Overview

This project creates an employee table, inserts employee records, and retrieves data from the database.

📋 Requirements

  • MySQL or SQLite installed.
  • Basic SQL knowledge.
  • Understanding of CREATE TABLE.
  • Understanding of INSERT and SELECT.

💻 Source Code


CREATE TABLE Employees (

    ID INT PRIMARY KEY,

    Name VARCHAR(50),

    Job VARCHAR(50),

    Salary DECIMAL(10,2)

);

INSERT INTO Employees
VALUES

(1,'Ahmed','Manager',8500),

(2,'Sara','Developer',7000),

(3,'Omar','Designer',6200);

SELECT * FROM Employees;

📖 Code Explanation

CREATE TABLE creates the Employees table.

INSERT INTO adds employee records.

SELECT * displays all employees.

🖥️ Output

ID | Name | Job | Salary 1 | Ahmed | Manager | 8500 2 | Sara | Developer | 7000 3 | Omar | Designer | 6200
