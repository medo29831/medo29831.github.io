🏧 C++ Simple ATM System

Learn how to build a simple ATM system using C++.

📖 Project Overview

In this project, you will build a simple ATM system. The user can check their balance, deposit money, withdraw money, and exit the program.

📋 Requirements

  • C++ compiler (g++, MinGW, or Visual Studio).
  • Basic knowledge of cout and cin.
  • Understanding of if, else, and switch.
  • Basic knowledge of loops.

💻 Source Code


#include 

using namespace std;

int main()
{
    double balance = 1000;
    int choice;
    double amount;

    cout << "===== ATM MENU =====" << endl;
    cout << "1. Check Balance" << endl;
    cout << "2. Deposit Money" << endl;
    cout << "3. Withdraw Money" << endl;
    cout << "4. Exit" << endl;

    cout << "Choose: ";
    cin >> choice;

    switch(choice)
    {
        case 1:
            cout << "Balance: $" << balance;
            break;

        case 2:
            cout << "Enter amount: ";
            cin >> amount;
            balance += amount;
            cout << "New Balance: $" << balance;
            break;

        case 3:
            cout << "Enter amount: ";
            cin >> amount;

            if(amount <= balance)
            {
                balance -= amount;
                cout << "New Balance: $" << balance;
            }
            else
            {
                cout << "Insufficient Balance!";
            }

            break;

        case 4:
            cout << "Goodbye!";
            break;

        default:
            cout << "Invalid Choice!";
    }

    return 0;
}

📖 Code Explanation

1. Create Balance

The program starts with a balance of $1000.

2. Display Menu

The ATM displays four options for the user.

3. Read User Choice

The program uses cin to read the user's choice.

4. Execute the Selected Option

The switch statement performs the selected ATM operation.

5. Update Balance

The balance changes after depositing or withdrawing money.
