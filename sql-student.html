📚 Student Database

Learn how to create and manage a student database using SQL.

📖 Project Overview

This project creates a database table for students and stores information such as ID, name, age, and grade.

📋 Requirements

  • MySQL or SQLite installed.
  • Basic SQL knowledge.
  • Understanding of CREATE TABLE.
  • Understanding of INSERT statements.

💻 Source Code


CREATE TABLE Students (

    ID INT PRIMARY KEY,

    Name VARCHAR(50),

    Age INT,

    Grade VARCHAR(5)

);

INSERT INTO Students
VALUES

(1,'Ali',18,'A'),

(2,'Sara',19,'B'),

(3,'Omar',18,'A');

SELECT * FROM Students;

📖 Code Explanation

CREATE TABLE creates a new table.

INSERT INTO adds new records.

SELECT * displays all records.

🖥️ Output

ID | Name | Age | Grade 1 | Ali | 18 | A 2 | Sara | 19 | B 3 | Omar | 18 | A
