📖 What is Python?

Python is a high-level programming language created by Guido van Rossum in 1991. It is widely used in web development, artificial intelligence, cybersecurity, data science, automation, and software development.

⭐ Features of Python

  • Easy to Learn
  • Simple Syntax
  • Open Source
  • Cross Platform
  • Large Community
  • Powerful Libraries

💻 Install Python

How to download Python on your device?

There are four of the most common operating systems on which Python can be installed.

  • 🪟 Windows
  • 🍎 macOS
  • 🐧 Linux
  • 💻 ChromeOS

In this section, you will learn how to install Python on the Windows operating system step by step

💻 Install Python on Windows

Steps:
  1. 1-Visit the official Python website
  2. 2-Click to Downloads

    3. This will take you to another page on the same site where you will see Python 3.14.6the latest version available at this time

  3. 3-Open the downloaded installer
  4. 4-Check Add Python to PATH
  5. 5-Click Install Now
  6. 6-Wait until the installation is complete
  7. 7-Open Command Prompt and type

python --version

If the Python version appears, the installation was successful. ✅

How to Install Python on macOS🍎❓

Steps:
  1. 1-Visit the official Python website
  2. 2-Click Download Python to download the latest version for macOS
  3. 3-Open the downloaded installer
  4. 4-Follow the installation instructions by clicking Continue and then Install
  5. 5-Enter your Mac password if prompted
  6. 6-Wait for the installation to finish, then click Close

Verify the Installation

  1. 7-Open the Terminal application
  2. 8-Type the following command

python --version

1-Press Enter

2-If the Python version is displayed, Python has been installed successfully ✅

How to Install Python on 🐧 Linux?

Steps:
  1. 1-Open the Terminal
  2. 2-Update the package list by running

sudo apt update

3-Install Python by running


    sudo apt install python3

4-Wait for the installation to complete

Verify the Installation

  1. 1-Open the Terminal
  2. 2-Type the following command

3-Install Python by running


python3 --version
  1. 3-Press Enter
  2. 4-If the Python version is displayed, Python has been installed successfully ✅

How to Install Python on ChromeOS?

Steps:
  1. 1-Open Settings
  2. 2-Go to Developers
  3. 3-Turn on Linux Development Environment
  4. 4-Wait for the installation to complete
  5. 5-Open the Terminal application
  6. 6-Update the package list by running

sudo apt update
  • 7-Install Python by running

sudo apt install python3

Verify the Installation

  • 1-In the Terminal, type:

python3 --version
  • 2-Press Enter
  • 3-If the Python version is displayed, Python has been installed successfully ✅
