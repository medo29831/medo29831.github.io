🧮 JavaScript Calculator

Learn how to build a simple calculator using JavaScript.

📖 Project Overview

In this project, you will create a calculator that performs basic arithmetic operations using JavaScript and HTML.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of JavaScript.
  • Variables.
  • Functions.
  • if / else statements.
  • DOM Manipulation.

💻 Source Code



let num1 = 10;

let num2 = 5;

let result = num1 + num2;

console.log(result);

📖 Code Explanation

1. Variables

Two variables are created to store the numbers.

2. Calculation

JavaScript adds the two numbers together.

3. Output

The result is displayed using console.log().

🖥️ Output

15

Modify the program so it performs subtraction, multiplication, and division.
