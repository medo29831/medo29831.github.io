💜 C# Programming

Learn one of the most powerful programming languages developed by Microsoft. C# is widely used for desktop applications, web development, game development with Unity, and much more.

📖 What is C#?

C# (pronounced "C Sharp") is a modern, object-oriented programming language created by Microsoft in 2000. It is part of the .NET platform and is used to build Windows applications, web applications, games, cloud services, and mobile apps.

Anders Hejlsberg is the creator of C#. He developed the language at Microsoft in 2000 to create modern, powerful, and easy-to-use software.

⭐ Features of C#

  • Object-Oriented Programming (OOP)
  • Simple and Modern Syntax
  • Powerful .NET Framework
  • Cross Platform with .NET
  • Fast Performance
  • Large Community
  • Used for Unity Game Development
  • Developed by Microsoft

💻 First C# Program


using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}

📖 Code Explanation

using System; imports the System namespace.

class Program creates the main class.

static void Main() is the entry point of the program.

Console.WriteLine() prints text on the screen.

🖥️ Output

Hello, World!

💻 Install C#

How to install C# on your device?

  • 🪟 Windows
  • 🍎 macOS
  • 🐧 Linux
  • 💻 ChromeOS

🪟 Install C# on Windows

Follow these steps to install C# on Windows:

  1. Visit the official .NET website.
  2. Download the latest .NET SDK.
  3. Run the installer.
  4. Follow the installation instructions.
  5. Open Command Prompt.
  6. Type the following command:

dotnet --version

If the .NET version appears, the installation was successful. ✅

🍎 Install C# on macOS

  1. Download the latest .NET SDK for macOS.
  2. Open the installer.
  3. Complete the installation.
  4. Open Terminal.
  5. Run:

dotnet --version

🐧 Install C# on Linux

Update the package list:


sudo apt update

Install the .NET SDK:


sudo apt install dotnet-sdk-8.0

Verify the installation:


dotnet --version

💻 Install C# on ChromeOS

  1. Enable Linux Development Environment.
  2. Open Terminal.
  3. Install the .NET SDK.
  4. Run:

dotnet --version
