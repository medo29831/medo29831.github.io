🗄️ SQL Programming

Learn SQL, the language used to manage and query databases.

📖 What is SQL?

SQL stands for Structured Query Language. It is the standard language used to create, manage, and retrieve data from relational databases such as MySQL, SQL Server, PostgreSQL, and SQLite.

SQL was created by Donald D. Chamberlin and Raymond F. Boyce at IBM in the early 1970s. It became the standard language for managing relational databases.

⭐ Features of SQL

  • Easy to Learn
  • Simple Syntax
  • Works with Databases
  • Fast Data Retrieval
  • Supports Large Databases
  • Cross Platform

💻 First SQL Program


SELECT * FROM Students;

📖 Code Explanation

SELECT retrieves data from a table.

* means all columns.

FROM Students specifies the table name.

🖥️ Output

ID | Name | Age 1 | Ali | 18 2 | Sara | 20 3 | Omar | 19

🪟 Install SQL on Windows

Follow these steps to start using SQL:

  1. Download MySQL Community Server.
  2. Install MySQL Workbench.
  3. Complete the installation wizard.
  4. Open MySQL Workbench.
  5. Create a new database.

🍎 Install SQL on macOS

  1. Download MySQL for macOS.
  2. Install MySQL Server.
  3. Install MySQL Workbench.
  4. Connect to your database.

🐧 Install SQL on Linux

Update your packages:


sudo apt update

Install MySQL Server:


sudo apt install mysql-server

Check the installed version:


mysql --version

💻 Install SQL on ChromeOS

  1. Enable Linux Development Environment.
  2. Open Terminal.
  3. Install MySQL.
  4. Verify the installation.

mysql --version
