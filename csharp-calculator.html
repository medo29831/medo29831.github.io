🧮 Calculator

Learn how to build a simple calculator using C#.

📖 Project Overview

This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

📋 Requirements

  • .NET SDK installed.
  • Visual Studio or Visual Studio Code.
  • Basic knowledge of variables.
  • Console input and output.
  • if / else statements.

💻 Source Code


using System;

class Program
{
    static void Main()
    {
        double num1, num2;
        char op;

        Console.Write("Enter first number: ");
        num1 = Convert.ToDouble(Console.ReadLine());

        Console.Write("Enter operator (+ - * /): ");
        op = Convert.ToChar(Console.ReadLine());

        Console.Write("Enter second number: ");
        num2 = Convert.ToDouble(Console.ReadLine());

        if(op == '+')
            Console.WriteLine("Result = " + (num1 + num2));

        else if(op == '-')
            Console.WriteLine("Result = " + (num1 - num2));

        else if(op == '*')
            Console.WriteLine("Result = " + (num1 * num2));

        else if(op == '/')
        {
            if(num2 != 0)
                Console.WriteLine("Result = " + (num1 / num2));
            else
                Console.WriteLine("Cannot divide by zero.");
        }

        else
            Console.WriteLine("Invalid operator.");
    }
}

📖 Code Explanation

1. Variables

The program stores two numbers and one operator.

2. Console.ReadLine()

Reads the user's input.

3. if / else

Determines which arithmetic operation to perform.

4. Division Check

The program prevents division by zero.

🖥️ Output

Enter first number: 10 Enter operator (+ - * /): * Enter second number: 5 Result = 50
