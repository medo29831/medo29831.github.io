🎲 C++ Guess the Number Project

Learn how to build a fun guessing game using C++.

📖 Project Overview

In this project, you will build a game where the computer generates a random number between 1 and 100. The player must guess the correct number. The program will tell the player whether the guess is too high, too low, or correct.

📋 Requirements

  • C++ compiler (g++, MinGW, or Visual Studio).
  • Basic knowledge of cout and cin.
  • Understanding of if, else if, and else.
  • Basic knowledge of loops.
  • Understanding of the cstdlib and ctime libraries.

💻 Source Code


#include 
#include 
#include 

using namespace std;

int main()
{
    srand(time(0));

    int secret = rand() % 100 + 1;
    int guess;

    cout << "Guess a number (1-100): ";
    cin >> guess;

    if (guess == secret)
    {
        cout << "🎉 Correct!";
    }
    else if (guess < secret)
    {
        cout << "⬇️ Too Low!";
    }
    else
    {
        cout << "⬆️ Too High!";
    }

    return 0;
}

📖 Code Explanation

1. Include Libraries

The program includes iostream for input/output, cstdlib for random numbers, and ctime to generate a different random number every time.

2. Generate a Random Number

The function rand() creates a random number, and srand(time(0)) changes the random seed every time the program runs.

3. Get User Input

The player enters a number using cin.

4. Compare the Guess

The program uses if, else if, and else to compare the player's guess with the secret number.

5. Display the Result

The program tells the player whether the guess is correct, too high, or too low.
