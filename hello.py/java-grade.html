📚 Student Grade Calculator

Learn how to calculate a student's average grade and determine whether the student passed or failed using Java.

📖 Project Overview

In this project, you will create a program that reads three subject grades, calculates the average, and determines whether the student passes or fails.

📋 Requirements

  • Java JDK installed.
  • Basic knowledge of variables.
  • Scanner class.
  • Arithmetic operators.
  • if / else statements.

💻 Source Code


import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.print("Enter first grade: ");
        double grade1 = input.nextDouble();

        System.out.print("Enter second grade: ");
        double grade2 = input.nextDouble();

        System.out.print("Enter third grade: ");
        double grade3 = input.nextDouble();

        double average = (grade1 + grade2 + grade3) / 3;

        System.out.println("Average = " + average);

        if(average >= 50){

            System.out.println("Status: Passed");

        }

        else{

            System.out.println("Status: Failed");

        }

        input.close();

    }

}

📖 Code Explanation

1. Scanner

The Scanner class reads the student's grades from the keyboard.

2. Average Calculation

The program calculates the average by adding the three grades and dividing by 3.

3. if / else

If the average is 50 or higher, the student passes; otherwise, the student fails.
