⏰ Digital Clock

Learn how to create a live digital clock using JavaScript.

📖 Project Overview

In this project, you will build a digital clock that displays the current time and updates every second using JavaScript.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of CSS.
  • Basic knowledge of JavaScript.
  • Functions.
  • Date Object.
  • setInterval().

💻 Source Code


function updateClock(){

let now = new Date();

document.getElementById("clock").innerHTML =
now.toLocaleTimeString();

}

setInterval(updateClock,1000);

📖 Code Explanation

1. Date()

Creates an object containing the current date and time.

2. toLocaleTimeString()

Returns the current time as a readable string.

3. setInterval()

Runs the function every 1000 milliseconds (1 second).
