📦 Styled Card

Learn how to create a modern card using CSS.

📖 Project Overview

In this project, you will build a stylish card that contains an image, a title, a description, and a button. You will also learn how to add shadows, rounded corners, spacing, and hover effects.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of CSS.
  • Understanding of colors and spacing.
  • Basic knowledge of hover effects.

💻 Source Code


<div class="card">

    <img src="images/profile.jpg" alt="Profile">

    <h2>John Doe</h2>

    <p>
    Front-End Developer
    </p>

    <button>
    View Profile
    </button>

</div>


.card{

background:#222;

width:300px;

padding:20px;

margin:auto;

text-align:center;

border-radius:15px;

box-shadow:0 0 15px rgba(0,0,0,.4);

transition:.3s;

}

.card img{

width:120px;

height:120px;

border-radius:50%;

}

.card button{

background:#2196F3;

color:white;

padding:12px 20px;

border:none;

border-radius:8px;

cursor:pointer;

}

.card:hover{

transform:translateY(-8px);

box-shadow:0 0 20px #00BFFF;

}

📖 Code Explanation

1. Card Container

The .card class creates the main card with padding, rounded corners, and a shadow.

2. Profile Image

The image is displayed as a circle using border-radius: 50%.

3. Button

The button is styled with a background color, rounded corners, and a pointer cursor.

4. Hover Effect

The card moves slightly upward and its shadow becomes brighter when the mouse is placed over it.

🖥️ Output

John Doe

Front-End Developer
