🖼️ Image Gallery Layout

Learn how to build a beautiful and responsive image gallery using CSS Grid.

📖 Project Overview

In this project, you will create a responsive image gallery. You will learn how to organize images using CSS Grid, add spacing, rounded corners, shadows, and hover effects.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of CSS.
  • Understanding of CSS Grid.
  • Basic knowledge of hover effects.

💻 Source Code


<div class="gallery">

    <img src="images/photo1.jpg" alt="Photo 1">

    <img src="images/photo2.jpg" alt="Photo 2">

    <img src="images/photo3.jpg" alt="Photo 3">

    <img src="images/photo4.jpg" alt="Photo 4">

</div>


.gallery{

display:grid;

grid-template-columns:repeat(auto-fit,minmax(220px,1fr));

gap:20px;

padding:20px;

}

.gallery img{

width:100%;

border-radius:15px;

box-shadow:0 0 12px rgba(0,0,0,.4);

transition:.3s;

}

.gallery img:hover{

transform:scale(1.05);

box-shadow:0 0 20px #00BFFF;

}

📖 Code Explanation

1. CSS Grid

The display: grid property creates a responsive image layout.

2. Grid Columns

The grid-template-columns property automatically adjusts the number of columns based on the screen size.

3. Gap

The gap property adds space between images.

4. Hover Effect

The images become larger and display a blue shadow when the mouse moves over them.

🖥️ Output

🎯 Exercise

Create your own responsive image gallery that includes:

  • At least four images.
  • Rounded corners for every image.
  • A shadow around each image.
  • A hover effect that enlarges the image.
  • A responsive layout using CSS Grid.
