✂️ C++ Rock Paper Scissors Project

Learn how to build the classic Rock Paper Scissors game using C++.

📖 Project Overview

In this project, you will build the classic Rock Paper Scissors game. The player chooses Rock, Paper, or Scissors, while the computer makes a random choice. The program then determines the winner.

📋 Requirements

  • C++ compiler (g++, MinGW, or Visual Studio).
  • Basic knowledge of cout and cin.
  • Understanding of if, else if, and else.
  • Basic knowledge of random numbers using rand().

💻 Source Code


#include 
#include 
#include 

using namespace std;

int main()
{
    srand(time(0));

    int player, computer;

    cout << "1 = Rock" << endl;
    cout << "2 = Paper" << endl;
    cout << "3 = Scissors" << endl;

    cout << "Choose: ";
    cin >> player;

    computer = rand() % 3 + 1;

    if(player == computer)
    {
        cout << "It's a Draw!";
    }
    else if(
        (player == 1 && computer == 3) ||
        (player == 2 && computer == 1) ||
        (player == 3 && computer == 2)
    )
    {
        cout << "You Win!";
    }
    else
    {
        cout << "Computer Wins!";
    }

    return 0;
}

📖 Code Explanation

1. Include Libraries

The program includes cstdlib and ctime to generate random choices for the computer.

2. Get Player Choice

The player selects Rock, Paper, or Scissors using cin.

3. Generate Computer Choice

The computer randomly chooses a number from 1 to 3.

4. Compare Choices

The program compares the player's choice with the computer's choice using if and else if statements.

5. Display the Winner

Finally, the program displays whether the player wins, the computer wins, or the game ends in a draw.
