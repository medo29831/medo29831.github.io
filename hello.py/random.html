🎲 Random Number Generator

Learn how to generate random numbers using JavaScript.

📖 Project Overview

In this project, you will build a simple random number generator. Each time the button is clicked, JavaScript generates a new random number.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of JavaScript.
  • Functions.
  • Variables.
  • Math.random()
  • Math.floor()

💻 Source Code


let number = Math.floor(Math.random() * 100) + 1;

console.log(number);

📖 Code Explanation

1. Math.random()

Generates a random decimal number between 0 and 1.

2. Math.floor()

Rounds the decimal number down to the nearest whole number.

3. Range

The program generates a random number from 1 to 100.

🖥️ Output

Random Number: 57
