CSS (Cascading Style Sheets) is the language used to style HTML pages. It controls colors, fonts, spacing, layouts, animations, and the overall appearance of a website.

🎨 What is CSS?

CSS is used to make websites beautiful and attractive. Without CSS, web pages would look plain with only text and simple elements.

Example

h1{
    color: blue;
}

p{
    font-size:20px;
}

⭐ Why is CSS Important?

CSS separates the design from the content, making websites easier to build, maintain, and customize.

  • Adds colors.
  • Changes fonts.
  • Creates layouts.
  • Makes websites responsive.

Example

body{
    background:#121212;
    color:white;
}

🎯 Why Should Beginners Learn CSS?

After learning HTML, CSS is the next step. It allows you to transform simple web pages into modern and professional websites.

  1. Easy to learn.
  2. Works with HTML.
  3. Creates beautiful designs.
  4. Responsive for all devices.
  5. Essential for web development.

💻 What Can You Do with CSS?

  • Change colors.
  • Create animations.
  • Design buttons.
  • Build responsive layouts.
  • Add shadows and borders.
  • Create modern user interfaces.

📄 Basic CSS Syntax

Every CSS rule consists of a selector and a declaration block. 

selector{

    property: value;

}

📌 Common CSS Properties

  • color → Text Color
  • background-color → Background Color
  • font-size → Font Size
  • width → Element Width
  • height → Element Height
  • margin → Outside Space
  • padding → Inside Space
  • border → Border
  • display → Display Type
  • position → Element Position

🖌 Example: Styling a Button

button{

    background:#1572B6;
    color:white;
    border:none;
    padding:10px 20px;
    border-radius:8px;

}

🏁 Conclusion

CSS is an essential technology for web development. It works together with HTML to create beautiful, responsive, and professional websites. Once you master CSS, you will be able to design modern web pages that look great on all devices.
