📚 C++ Student Grade Calculator

Learn how to build a student grade calculator using C++.

📖 Project Overview

In this project, you will build a program that calculates a student's average score and determines the final grade based on the average.

📋 Requirements

  • C++ compiler (g++, MinGW, or Visual Studio).
  • Basic knowledge of cout and cin.
  • Understanding of if, else if, and else.
  • Basic arithmetic operations.

💻 Source Code


#include 

using namespace std;

int main()
{
    float math, science, english;
    float average;

    cout << "Enter Math Grade: ";
    cin >> math;

    cout << "Enter Science Grade: ";
    cin >> science;

    cout << "Enter English Grade: ";
    cin >> english;

    average = (math + science + english) / 3;

    cout << "Average = " << average << endl;

    if (average >= 90)
        cout << "Grade: A";

    else if (average >= 80)
        cout << "Grade: B";

    else if (average >= 70)
        cout << "Grade: C";

    else if (average >= 60)
        cout << "Grade: D";

    else
        cout << "Grade: F";

    return 0;
}

📖 Code Explanation

1. Get Student Grades

The program asks the user to enter three subject grades.

2. Calculate the Average

The program calculates the average of the three grades.

3. Check the Grade

The program uses if and else if to determine the final grade.

4. Display the Result

Finally, the program prints both the average and the student's grade.
