🎲 Python Guess the Number Project

Learn how to build a guessing game using Python.

📖 Project Overview

In this project, you will build a game where the computer chooses a random number, and the player tries to guess it. The program gives hints if the guess is too high or too low.

📋 Requirements

  • Python 3 installed on your computer.
  • Basic knowledge of print() and input().
  • Understanding of if, elif, and else.
  • Basic knowledge of the random module.

💻 Source Code



import random

secret_number = random.randint(1, 100)

guess = int(input("Guess a number between 1 and 100: "))


if guess == secret_number:

    print("🎉 Correct! You guessed the number.")


elif guess < secret_number:

    print("⬇️ Too low!")


else:

    print("⬆️ Too high!")

📖 Code Explanation

1. Import random

The program imports the random module to generate a random number.

2. Create the secret number

The function random.randint() selects a random number between 1 and 100.

3. Get player's guess

The player enters a number using input().

4. Compare the numbers

The program uses if, elif, and else to check if the guess is correct, too high, or too low.

5. Display the result

The game gives hints to help the player find the correct number.
