☕ Java Calculator Project

Learn how to build a simple calculator using Java.

📖 Project Overview

In this project, you will build a calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

📋 Requirements

  • Java JDK installed.
  • Basic knowledge of variables.
  • Scanner class.
  • if / else statements.
  • Arithmetic operators (+, -, *, /).

💻 Source Code


import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        System.out.print("Choose (+, -, *, /): ");
        char op = input.next().charAt(0);

        System.out.print("First number: ");
        double num1 = input.nextDouble();

        System.out.print("Second number: ");
        double num2 = input.nextDouble();

        if(op == '+'){
            System.out.println(num1 + num2);
        }
        else if(op == '-'){
            System.out.println(num1 - num2);
        }
        else if(op == '*'){
            System.out.println(num1 * num2);
        }
        else if(op == '/'){
            if(num2 != 0){
                System.out.println(num1 / num2);
            }else{
                System.out.println("Cannot divide by zero");
            }
        }
        else{
            System.out.println("Invalid operator");
        }

        input.close();

    }

}

📖 Code Explanation

1. Scanner

The Scanner class is used to read input from the user.

2. Variables

The program stores the operator and two numbers entered by the user.

3. if / else

The program checks which arithmetic operation should be performed.

4. Division by Zero

Before division, the program checks if the second number is zero.
