🌙 Dark Mode Toggle

Learn how to switch between Light Mode and Dark Mode using JavaScript.

📖 Project Overview

In this project, you will create a button that changes the website theme between Light Mode and Dark Mode using JavaScript.

📋 Requirements

  • Basic knowledge of HTML.
  • Basic knowledge of CSS.
  • Basic knowledge of JavaScript.
  • Functions.
  • DOM Manipulation.
  • classList.toggle().

💻 Source Code


function toggleMode(){

document.body.classList.toggle("light-mode");

}

📖 Code Explanation

1. Function

The function runs when the button is clicked.

2. classList.toggle()

It adds the class if it doesn't exist, and removes it if it already exists.

3. Theme Switching

The page changes between Dark Mode and Light Mode.
