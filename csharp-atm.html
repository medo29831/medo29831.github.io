🏧 ATM System

Learn how to build a simple ATM system using C#.

📖 Project Overview

In this project, you will build a simple ATM system that allows users to check their balance, deposit money, withdraw money, and exit the program.

📋 Requirements

  • .NET SDK installed.
  • Visual Studio or Visual Studio Code.
  • Basic knowledge of variables.
  • while loop.
  • switch statement.
  • Console input/output.

💻 Source Code


using System;

class Program
{
    static void Main()
    {
        double balance = 1000;
        int choice;

        while(true)
        {
            Console.WriteLine("\n===== ATM MENU =====");
            Console.WriteLine("1. Check Balance");
            Console.WriteLine("2. Deposit");
            Console.WriteLine("3. Withdraw");
            Console.WriteLine("4. Exit");

            Console.Write("Choose: ");
            choice = Convert.ToInt32(Console.ReadLine());

            switch(choice)
            {
                case 1:
                    Console.WriteLine("Balance: $" + balance);
                    break;

                case 2:
                    Console.Write("Deposit amount: ");
                    balance += Convert.ToDouble(Console.ReadLine());
                    Console.WriteLine("Deposit successful.");
                    break;

                case 3:
                    Console.Write("Withdraw amount: ");
                    double amount = Convert.ToDouble(Console.ReadLine());

                    if(amount <= balance)
                    {
                        balance -= amount;
                        Console.WriteLine("Withdrawal successful.");
                    }
                    else
                    {
                        Console.WriteLine("Insufficient balance.");
                    }

                    break;

                case 4:
                    Console.WriteLine("Thank you for using the ATM.");
                    return;

                default:
                    Console.WriteLine("Invalid choice.");
                    break;
            }
        }
    }
}

📖 Code Explanation

1. Balance

A variable stores the current account balance.

2. while(true)

The menu keeps running until the user chooses Exit.

3. switch

Each menu option performs a different ATM operation.

4. if Statement

The program checks if there is enough balance before withdrawing money.
